Change the class login

For the teacher. This page makes a new login.js file for the Year 10 Media Exam Hub. Everything happens in your browser: nothing you type is sent anywhere or saved.

Current login
New login

The username is not case-sensitive. The password is. Use at least six characters.

Then upload it

  1. Your browser will download a file called login.js.
  2. In your GitHub repository, open the assets folder and choose Add file → Upload files.
  3. Drag in the new login.js so that it replaces the old one, then choose Commit changes.
  4. Wait a minute or two, then try the new login on the site. If the old one still works, refresh the page once.

Good to know: a student who ticked “Keep me signed in” stays signed in on that device until they sign out. Changing the login stops new sign-ins with the old password; it does not sign anyone out. To shut everyone out completely, the site needs to be rebuilt with a new key (see the README).
